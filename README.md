# The-Bard

## Purpose of The Bard
The purpose of the project is to create a website using HTML, CSS, Javascript, and DOM API that will allow its users to discover music artists, learn about them, and favorite them.

## How to use the website
Because this project is not yet completed, if the user is using VScode to view these files, they will need to load the text editor up. The user will then have to clone the repository, and open up the files. They must make sure they have the extension "Live Server" installed and enabled. After confirming that the extension is installed and enabled, the user will then have to navigate to the home.html file. In the bottom right corner of the Vs Code text editor, there will be a button that says "Go Live". They will have to click it to allow a pop up to appear that says "Open in browser" which they will then have to click. That button will open up a tab in their browser that shows all the files in this project, to get to the website, the user will have to select "home.html". That will take them to the home page of the website where they can navigate to all other pages we have set up.
