The Bard welcomes you!

The Bard is a web application that allows users to browse artists, search for artists, read information about artists, and save artists to a favorites page.This application provides a music discovery service for users and has user-friendly functionality. The intended users are music fans and anyone who wants to grow their love for music. The main page is the Home page, which contains navigation links to the other pages, a list of the application's features, and a description of the application. The Explore page displays all of The Bard's featured artists, along with an image and a description of each artist. There is a favorite button next to every artist, which allows users to add the artist to their favorites list. Additionally, there is a search bar that lets users search for a specific artist and jump to their location on the page. Finally, the Favorites page holds a user's favorite artists. On this page, users can read information about each artist or remove an artist from their favorites list.
